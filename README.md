# Professional Developer Portfolio

This is a modern, single-page professional portfolio for a Full-Stack Developer, designed to showcase skills, projects, and experience in a visually appealing and interactive manner. The portfolio is built with React, TypeScript, and Tailwind CSS, focusing on a clean aesthetic, smooth animations, and a great user experience.

## Features

-   **Modern & Responsive Design**: Fully responsive layout that looks great on all devices, from mobile phones to desktops.
-   **Smooth Scrolling Navigation**: A fixed header with navigation links that smoothly scroll to the corresponding sections of the page.
-   **Interactive UI Elements**: Engaging hover effects, animations, and a unique "spotlight" cursor effect that follows the user's mouse for an enhanced experience.
-   **Dynamic Content Sections**:
    -   **Hero**: A striking introduction with clear calls-to-action.
    -   **About Me**: A personal summary and educational background.
    -   **Skills**: A categorized showcase of technical proficiencies with icons.
    -   **Projects**: A grid of selected works with images, descriptions, and technologies used.
-   **Project Details Modal**: Clicking "View Details" on a project opens an elegant modal with an in-depth case study (challenge, solution, and outcome).
-   **Scroll-Triggered Animations**: Sections gracefully fade into view as the user scrolls down the page.
-   **Contact Section**: Direct links to email and LinkedIn for easy contact.

## Getting Started

To run this project locally, follow these steps:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (version 16 or later) and a package manager like `npm` or `yarn` installed on your machine.

### Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/your-repo-name.git
    cd your-repo-name
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```
    or
    ```bash
    yarn install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```
    or
    ```bash
    yarn dev
    ```
    This will start the development server. Open your browser and navigate to `http://localhost:5173` (or the URL provided in your terminal) to see the application.

### Building for Production

To create a production-ready build of the application:

```bash
npm run build
```
or
```bash
yarn build
```
This command will generate a `dist` folder with optimized static assets that are ready to be deployed to a web server or hosting service.
